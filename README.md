# 수학 일기 (구월중학교)

중학생이 **수학 수업이 있는 날마다** 배운 것과 느낀 점을 남기는 웹앱.
학년·반·번호를 고르고 생년월일로 들어오면, 나이스 시간표에서 찾아온 수학 수업이
달력에 `3교시 수학` 처럼 표시되고, 그 칸을 눌러 일기를 씁니다.

## 구조 — 하이브리드

```
GitHub Pages (이 저장소)          Apps Script (/exec)
  index.html   학생 화면   ──fetch(JSON)──▶  doPost 라우터
  teacher.html 교사 화면                      ├─ 스프레드시트(명렬표·일기·쪽지)
  config.js    서버 주소                      └─ 나이스 misTimetable (키는 서버에만)
  style.css
```

화면을 정적 페이지로 뺀 이유:

- Apps Script 가 HTML 을 만들어 내려주면 **첫 렌더에 10~30초**가 걸린다. 수업 끝나고
  태블릿 30대가 한꺼번에 열면 이건 실패다. 정적 페이지는 즉시 뜬다.
- JSON 만 주고받으니 **스크립트 실행시간**(개인 계정 하루 90분)이 크게 줄어든다.
- 교차출처 iframe(`googleusercontent.com`)에서 벗어나 **개발자도구로 화면을 볼 수 있다**.
- 그러면서도 **인증과 나이스 키는 서버에 남는다** — 파이어베이스 무료 플랜에는 서버가 없어
  생년월일 대조를 클라이언트에서 해야 하고, 그러려면 명렬표 전체를 브라우저에 내려야 한다.

## 서버 주소를 바꿀 때

`config.js` 의 `window.ENDPOINT` 한 줄만 고친다.
같은 배포ID 로 다시 올리면(`clasp redeploy <배포ID>`) 주소는 그대로다.

## 서버 쪽 (이 저장소 바깥)

`…\수학과\수학 일기앱\server` (clasp). 학생 개인정보가 오가므로 저장소에 넣지 않는다.

- 처음 한 번 : 편집기에서 `설치()` 실행 → 시트 생성 + 교사 비밀번호 발급(로그에 찍힘)
- 설정은 스프레드시트 `설정` 탭에서 바꾼다(담당반, 과목명, 작성마감일수, 앱사용, 공지)

## 알아 둘 것

- **미래 수업은 못 쓴다.** 배우지 않은 것을 쓸 수는 없으니까.
- **작성 기한은 기본 7일**(`설정` 탭에서 바꿀 수 있음).
- 별점·세 칸 모두 선택이지만 **전부 비면 저장하지 않는다.**
- 입력 중 내용은 브라우저에 임시저장된다(새로고침·화면 잠김에도 살아남음).
- 쪽지는 일기와 **다른 시트**에 쌓인다. 교사 화면에서 답장을 달면 학생이 다음에 본다.
